# Argus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建 Argus——一个 AI 白盒代码扫描工具,以 codegraph 为共享事实层,用可插拔分析器发现漏洞,由 LangGraph 编排成可停可续、人在环路的五阶段管线。

**Architecture:** LangGraph `StateGraph` 编排五阶段(建图 → 富化 → 漏洞分析 → 验证 → 报告);每个分析器是一个可插拔节点,实现统一 `Analyzer` 协议,读同一份只读 `AnalysisContext`,产出统一 `Finding`;`SqliteSaver` 做节点级 checkpoint,`interrupt()` 做人工检查点。

**Tech Stack:** Python 3.11+、LangGraph、Anthropic SDK、codegraph CLI/DB(SQLite)、pytest、ruff、mypy、PyYAML。

## Global Constraints

- Python 3.11+;依赖用 `uv` 或 `pip` 管理,锁定在 `pyproject.toml`。
- 契约权威定义在 `docs/contracts/interfaces.py`;`argus/contracts.py` 必须与之逐字一致。
- 所有 Finding 的 `locations[].node_id` 必须是 codegraph 中真实存在的节点 id。
- 分析器不直接碰 SQLite——只通过 `GraphHandle` 协议访问 codegraph。
- 图组/无图组严格隔离:漏洞分析器读图与富化产物,基线组只读源码,互不偷看。
- 防泄露:靶场评测强制 `source_mode=stripped`。
- 质量门:`ruff check` + `ruff format --check` + `mypy argus/` + `pytest -q` 全绿,外加对方 agent 交叉评审。
- 提交用 conventional commits;commit message 末尾加 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`。
- 不做动态验证/漏洞利用/浏览器自动化/Temporal/Docker。
